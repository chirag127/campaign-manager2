AdVantage

Manage your advertising campaigns across all platforms from a single, sleek dashboard.

View on GitHub

Key Features

  • 🔧 Full CRUD API built with Flask.
  • 📱 Mobile‑first responsive design.
  • 💎 Modern glassmorphism UI.
  • 🚀 Live demo hosted on GitHub Pages.

Live Demo

Interact with the API using the Swagger UI (available at /swagger when running locally) or try the sample requests below.

curl -X POST http://127.0.0.1:5000/api/campaigns \
-H "Content-Type: application/json" \
-d '{"name":"Spring Sale","budget":5000,"start_date":"2024-04-01","end_date":"2024-04-30","status":"active"}'
